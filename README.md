# 🏦 Online Bank Management System

A simple web-based banking application built with **Java Servlets, JSP, and JDBC**, connected to a **MySQL** database. This project demonstrates core Advanced Internet Programming concepts along with Advanced Database Management System (ADBMS) principles such as CRUD operations and ACID transaction properties.

---

## 📋 Features

- User Registration & Login (with session management)
- Auto-generated bank account on registration
- Deposit funds
- Withdraw funds (with balance validation)
- Transfer funds between accounts (with transaction rollback demo)
- Mini statement (transaction history)
- Session timeout with live countdown timer
- Input validation (no zero/negative amounts)
- Database-level balance constraint (CHECK >= 0)
